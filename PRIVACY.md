# 隱私權政策 / Privacy Policy

最後更新 / Last updated: 2026-11-09

## 中文

「Gmail Helper」（以下稱本工具）是開發者個人自用的程式，不對外開放。

- 本工具經 Google OAuth 授權後，只存取開發者本人的 Gmail 帳戶，用途僅限於讀取指定信件。
- 本工具不會將任何 Gmail 資料出售、分享或傳送給第三方。
- 資料只在執行時於本機處理，不儲存於任何外部伺服器；授權 token 僅存放在開發者本人的電腦上。
- 可隨時到 Google 帳戶的「第三方應用程式與服務」頁面撤銷本工具的存取權。
- 本工具對 Google API 所取得資料的使用與傳輸，遵守 Google API 服務使用者資料政策（Google API Services User Data Policy），包括「有限使用（Limited Use）」規定。

聯絡方式：your-email@gmail.com

## English

Gmail Helper ("the App") is a personal tool used only by its developer and is not offered to the public.

- After authorization via Google OAuth, the App accesses only the developer's own Gmail account, solely to read specified emails.
- The App does not sell, share, or transfer any Gmail data to third parties.
- Data is processed locally at runtime and is not stored on any external server. OAuth tokens are stored only on the developer's own computer.
- Access can be revoked at any time from the "Third-party apps & services" page of the Google Account.
- The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
